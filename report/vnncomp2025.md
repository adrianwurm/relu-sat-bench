# VNN-COMP 2025: network size where the verifiers failed

Generated by `python -m relu_sat_bench.vnncomp report` from `results/vnncomp2025/`, which `collect` builds from the public repositories `VNN-COMP/vnncomp2025_results` (official per-instance table: *no tool* = no participating tool answered; α,β-CROWN's own `results.csv`) and `VNN-COMP/vnncomp2025_benchmarks` (the networks).

*Parameters*: every floating-point number in the initializers and Constant nodes of the ONNX file (weights, biases, normalisation constants), zeros included; *nonzero*: those that are not 0. Trained networks have almost all parameters nonzero. VNN-COMP ran on AWS instances chosen by the teams, with time limits set per benchmark; relu-sat-bench: 60 s per instance, 4 CPU cores, no GPU.

Not counted: `cGAN_imgSz32_nCh_3_small_transformer.onnx` (not in the repository), `mscn_2048d_dual.onnx` (unreadable: DecodeError), `vgg16-7.onnx` (not in the repository).
